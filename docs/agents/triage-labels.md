# 分诊标签

这些工程技能会使用五个固定的“分诊角色”。本文件把这些角色映射到仓库实际使用的标签字符串。

| 技能中的角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者先评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 信息充分，可由 agent 直接处理 |
| `ready-for-human` | `ready-for-human` | 需要人类实现或决策 |
| `wontfix` | `wontfix` | 不会继续处理 |

当技能提到某个角色时，使用本表右侧对应的实际标签名。
如果以后仓库标签词表发生变化，只需要修改本文件右侧列即可。
