# GUI 使用指南

版本：1.0.0
变更日期：2026-05-13
影响范围：`gui_example.py`、CAD 预览输出、配置说明

## 启动

```powershell
conda activate cad_study
cd E:\Code\CAD
D:\anaconda3\envs\cad_study\python.exe gui_example.py
```

GUI 默认扫描 `examples/cad_files`，输出写入 `examples/output`。

## 主要功能

| 区域 | 功能 |
|---|---|
| 顶部设置 | 配置 DeepSeek API Key、FreeCAD 路径、默认输出目录、缓存目录和逐阶段确认开关 |
| 左侧控制区 | 设置处理参数、控制处理流程、在 CAD 文件列表中选择输入目录并刷新/预览文件 |
| 右侧预览区 | 显示 CAD 图纸 PNG 预览 |
| 底部日志区 | 显示处理进度、错误信息、输出目录 |

## 设置入口

顶部菜单左侧的“设置”用于修改运行配置和系统设置：

- DeepSeek API Key 与 FreeCAD bin 目录写入项目根目录 `.env`。
- 默认输出目录、分析缓存目录和“逐阶段确认”写入 `config/gui_config.json`。
- FreeCAD 增强包仍可放在 `tools/freecad/FreeCAD-1.0.x/bin/python.exe`，优先级高于设置窗口中的 `FREECAD_BIN_PATH`。
- 保存后，新配置会在下一次处理任务中生效。

## 预览行为

预览逻辑已调整为稳定文件输出，不再使用临时文件。

输出路径：

```text
examples/output/<图纸名>/<图纸名>_preview.png
```

影响：

- 预览图可复用，便于调试和文档引用。
- 不再调用 `plt.show()`，可在无头服务器或 CI 环境中生成预览。
- 如果解析到 0 个实体，GUI 会记录提示并停止预览生成，避免空图覆盖有效缓存。

## 基础处理流程

1. 启动 GUI。
2. 在文件列表中选择或双击图纸。
3. 点击“预览选中”生成/查看预览图。
4. 默认开启“逐阶段确认”。
5. 点击“开始处理”。
6. 查看底部日志和输出目录。

## 智能处理

处理前，请确认 `.env` 中存在：

```env
DEEPSEEK_API_KEY=your-deepseek-api-key-here
```

GUI 统一使用智能处理入口。系统会使用 DeepSeek 相关配置理解图纸，并在内部选择平面拉伸路径或语义重建路径。

## 逐阶段确认

GUI 单图纸智能处理默认开启“逐阶段确认”；该机制不用于批处理。开启后，系统会在以下大模型阶段完成后停止并显示汇报：

1. 视图语义校正。
2. 零件语义重建。

汇报窗口使用“停止 / 继续”表示当前分支：继续会放行下一阶段，停止会结束本次处理。如果继续后马上需要追问补充信息，或当前结果存在明显风险，系统会先在汇报中提示建议动作；正常情况下不额外显示这类提示。追问窗口仍负责收集补充信息；阶段汇报只负责审阅和分流。

关闭“逐阶段确认”后，系统会按原流程自动完成分析、建模路径选择和后续执行。

## 追问与补充提示

当系统无法在安全边界内继续自动处理时，会进入追问窗口。窗口会列出结构化问题，并允许填写“补充给大模型的建模提示”。补充提示会随已解析图纸、尺寸裁决和语义上下文一起传给后续大模型，用于说明建模意图、细节优先级或哪些细节可以接受跳过。

结构化问题会尽量使用图纸语言描述，例如“主视图水平总尺寸”“厚度或拉伸深度”，而不是要求用户理解内部语义字段。看不出来时，可以选择“不确定”或在补充提示中说明自己的判断。

每个结构化问题下方可能显示一行“为什么问”，用于说明该问题影响的建模风险或关键尺寸，不需要把它当成额外问题回答。

部分问题还会显示“示例”，例如 `10mm`、`Z 方向` 或“选择图纸上表示总尺寸的值”。示例只说明填写格式，不代表系统已经替用户选择了答案。

补充提示不是本地强制覆盖规则；系统不会用关键词判断它是否冲突。大模型处理补充提示时仍必须以图纸事实、标注尺寸、已裁决关键尺寸来源、主体方向和主体外形为优先依据。

## 常见问题

### 预览失败

检查：

- `matplotlib` 已安装。
- `ezdxf` 已安装。
- DWG 文件默认使用项目内置 `tools/bin/dwg2dxf.exe`，也可通过 `LIBREDWG_PATH` 指定外部路径。

### FreeCAD 不可用

设置：

```env
FREECAD_BIN_PATH=D:\FreeCAD 1.0\bin
```

如果未设置，系统会尝试自动扫描常见 Windows 安装目录。

### 日志中是否会泄露密钥

`setup_logging()` 已添加 `SensitiveDataFilter`，会脱敏常见 API Key 和 token 模式。但不要主动打印 `.env`、完整配置对象或请求头。
