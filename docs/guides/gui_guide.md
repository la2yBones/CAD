## 1. 启动方式

### 方式一：系统 Python 启动（推荐）

```bash
conda activate cad_study
python gui_example.py
```

> 系统会自动检测 FreeCAD 安装路径，并通过子进程调用 FreeCAD 完成建模。

### 方式二：FreeCAD 内置 Python 启动

```bash
run_with_freecad.bat gui_example.py
```

> 如果希望直接复用 FreeCAD 自带的 Python 环境，可使用此脚本。脚本会自动定位 FreeCAD 的 `python.exe`。

### 启动后

窗口标题栏显示 `CAD图纸3D建模工具 v0.3.0`，界面自动加载 `examples/cad_files` 目录中的所有 CAD 文件。

## 3. 左侧面板：控制区

### 3.1 控制工具栏

三个按钮，从左到右：

| 按钮 | 功能 | 说明 |
|------|------|------|
| **选择文件夹** | 切换 CAD 文件输入目录 | 弹出系统文件夹对话框，选择后列表自动刷新 |
| **刷新列表** | 重新扫描当前输入目录 | 当目录中文件有增减时使用 |
| **预览选中** | 在右侧面板显示选中图纸的预览图 | 也可通过**双击**文件列表项触发 |

### 3.2 参数设置区

| 参数 | 类型 | 默认值 | 说明 |
|------|------|-------|------|
| **拉伸高度(mm)** | 数字输入框 | 10.0 | 2D 轮廓沿 Z 轴拉伸的厚度。典型值：薄板 3-5mm，厚板 10-20mm |
| **启用 AI 智能分析** | 复选框 | 关闭 | 开启后调用 DeepSeek API 进行视图识别、尺寸提取和 AI 建模指令生成。需要有效的 `config.yaml` 中的 `api.deepseek.api_key` |
| **仅处理选中** | 复选框 | 开启 | 开启时只处理文件列表中选中的单个文件；关闭时批量处理列表中所有文件 |

### 3.3 操作按钮

| 按钮 | 功能 | 启用条件 |
|------|------|---------|
| **▶ 开始处理** | 启动 CAD 文件处理任务 | 已选择文件（单文件模式）或列表非空（批量模式） |
| **✕ 取消** | 终止当前处理任务 | 处理进行中时自动变为可用 |

> 点击「开始处理」后，任务在**后台线程**中执行，窗口**不会卡死**，你可以继续浏览文件列表、查看预览或滚动日志。

### 3.4 进度条

- **进度条**：显示当前处理进度百分比（0%–100%）
- **进度文字**：显示 `当前序号/总数 处理: 文件名`
- 处理完成后进度条显示 100%，文字显示"完成: N 个文件"

### 3.5 文件列表

| 列名 | 说明 |
|------|------|
| **文件名** | CAD 图纸文件的完整名称（含 `.dxf` / `.dwg` 后缀） |
| **大小** | 文件大小（KB），供参考 |
| **状态** | 实时显示处理结果：`处理中` / `✓`（成功）/ `✗`（失败）/ 空白（未处理） |

交互方式：

| 操作 | 效果 |
|------|------|
| **单击** 某行 | 选中该文件，`_selected_file` 更新为当前文件名 |
| **双击** 某行 | 触发预览，在右侧面板显示该图纸的可视化效果 |

## 4. 右侧面板：图纸预览区

### 4.1 功能说明

预览区使用 `matplotlib` 的 `FigureCanvasTkAgg` 嵌入到 Tkinter 窗口中，实时渲染 CAD 图纸的 2D 可视化图像。预览图通过 ezdxf 的 `Frontend` 渲染引擎生成，显示内容包括：

- 所有几何实体（线条、圆弧、多段线、圆）
- 图层颜色区分
- 原始坐标系比例

### 4.2 使用方式

1. 在文件列表中**单击选中**一个文件
2. 点击「预览选中」按钮（或**双击**文件列表中的文件名）
3. 系统自动解析 CAD 文件并生成 PNG 预览图
4. 预览图在右侧面板显示

### 4.3 预览缓存

- 首次预览时，系统解析 CAD 并渲染 PNG，耗时约 **1-3 秒**
- 若该文件之前已被处理过，系统会优先从 `examples/output/<文件名>/<文件名>_preview.png` 读取缓存的预览图
- 缓存命中时加载速度 < 0.5 秒

## 5. 底部面板：日志与报告

### 5.1 日志区域

实时滚动显示以下信息：

- 管道初始化状态
- 每个文件的处理进度
- 每个文件的输出路径（geometry、step、stl、visualization...）
- 错误信息（如有）

日志格式示例：

```
管道初始化成功
刷新完成，共 51 个文件
[1/2] ✓ 底座二视图.dxf  实体: 20
    geometry: examples/output/底座二视图/底座二视图_geometry.json
    model_step: examples/output/底座二视图/底座二视图.step
    model_stl: examples/output/底座二视图/底座二视图.stl
=========================================================
处理完成
```

### 5.2 底部操作按钮

| 按钮 | 功能 | 启用条件 |
|------|------|---------|
| **打开 STEP 模型** | 用系统默认程序打开生成的 STEP 文件 | 至少有一个文件处理成功后启用 |
| **打开输出目录** | 在资源管理器中打开当前输出文件夹 | 至少有一个文件处理成功后启用 |
| **清空日志** | 清除日志区域所有内容 | 始终可用 |

> 点击「打开 STEP 模型」会调用 `os.startfile()`，Windows 上默认使用 FreeCAD 打开。你也可以将 `.step` 文件关联到其他 3D 查看器（如 Fusion 360、SolidWorks eDrawings）。

## 6. 完整操作流程

### 6.1 基础流程：单文件处理（最常用）

```
第1步：启动 GUI
    → conda activate cad_study
    → python gui_example.py

第2步：选择文件
    → 在左侧文件列表中单击你要处理的图纸（如"底座二视图.dxf"）
    → 文件高亮选中

第3步：预览（可选）
    → 双击文件名 或 点击「预览选中」
    → 右侧面板显示图纸 2D 可视化

第4步：调整参数
    → 拉伸高度：根据零件实际厚度修改（默认 10mm）
    → 确保 ☑ 仅处理选中 处于勾选状态
    → AI 分析可保持关闭（基础模式不需要 API Key）

第5步：开始处理
    → 点击 ▶ 开始处理
    → 观察进度条和日志区域
    → 状态列显示 处理中 → ✓（完成）

第6步：查看结果
    → 点击底部「打开 STEP 模型」→ FreeCAD 启动并加载 3D 模型
    → 或点击「打开输出目录」→ 资源管理器显示所有输出文件
```

### 6.2 批量处理流程

```
第2步修改为：
    → 取消勾选 ☐ 仅处理选中
    → 点击 ▶ 开始处理
    → 系统自动处理文件列表中所有图纸

第5步修改为：
    → 逐文件处理，每完成一个状态列更新（✓ / ✗）
    → 可随时点击 ✕ 取消 终止未完成的文件
    → 取消后已完成的文件结果保留
```

### 6.3 AI 智能分析流程

```
前置条件：config.yaml 中已配置有效的 DeepSeek API Key

第4步修改为：
    → 勾选 ☑ 启用 AI 智能分析
    → 点击 ▶ 开始处理

AI 模式下的处理流程：
    解析 CAD → 视图识别 → 尺寸提取 → 本地几何分析 → AI 建模指令 → 3D 生成
```

## 7. 常见使用场景

### 场景一：演示单个零件转换

**目标**：在答辩/汇报时快速展示单个零件的 2D→3D 转换效果

```
1. 启动 GUI
2. 双击"底座二视图.dxf" → 预览显示
3. 设置拉伸高度 10mm
4. 点击"开始处理"
5. 等待 2-3 秒处理完成
6. 点击"打开 STEP 模型" → FreeCAD 展示 3D 模型
7. 滚动/旋转 3D 模型展示转换效果
```

### 场景二：批量验证全部图纸

**目标**：一次性处理 51 张 CAD 图纸，验证系统稳定性

```
1. 取消勾选"仅处理选中"
2. 点击"开始处理"
3. 观察进度条和状态列
4. 全部完成后统计 ✓ 数量
5. 失败的文件在日志中查看具体错误原因
```

### 场景三：切换 CAD 图纸目录

**目标**：处理另一个目录中的 CAD 文件

```
1. 点击"选择文件夹"
2. 在对话框中导航到目标目录（如 D:\MyCAD\绘图）
3. 点击确定
4. 文件列表自动刷新为新目录内容
5. 继续正常使用
```

### 场景四：调试特定问题图纸

**目标**：排查某张图纸为何处理失败

```
1. 勾选"仅处理选中"
2. 选中问题图纸
3. 点击"开始处理"
4. 查看日志中的具体错误信息
5. 若为 FreeCAD 子进程错误，打开 cmd 手动运行 cad_cli.py 查看完整错误输出
```

## 8. 配置参数

GUI 启动时自动加载 `config/config.yaml` 中的配置。以下是与 GUI 操作相关的关键配置项：

### config.yaml 关键项

```yaml
# API 配置（AI 智能分析需要）
api:
  deepseek:
    api_key: "sk-xxxxxxxxxxxxxxxx"     # DeepSeek API Key
    base_url: "https://api.deepseek.com"
    model: "deepseek-v4-pro"           # 模型版本
    temperature: 0.3                   # 生成温度(0-1)

# FreeCAD 配置（建模必须）
freecad:
  bin_path: "D:\\FreeCAD 1.0\\bin"    # FreeCAD 安装目录
  script_timeout: 300                 # 子进程超时(秒)

# 建模配置
modeling:
  default_extrude_height: 10.0        # 默认拉伸高度(mm)
  default_units: "mm"
  export_formats:                     # 支持的导出格式
    - "STEP"
    - "STL"
    - "FCStd"
```

### 不依赖 API Key 的功能

即使没有配置 API Key，以下功能仍正常工作：

- CAD 文件解析（DXF/DWG）
- 图纸 2D 预览
- 几何图层分层拉伸建模
- STEP/STL/FCStd 导出
- 可视化 PNG 生成

## 9. 注意事项与最佳实践

### 9.1 输入文件要求

| 要求 | 说明 |
|------|------|
| **格式** | 支持 `.dxf` 和 `.dwg` 两种格式 |
| **图层规范** | 轮廓放在 `OUTLINE` 或含"轮廓"的图层；孔放在 `HOLES` 或含"孔"的图层；槽放在 `SLOTS` 或含"槽"的图层 |
| **编码** | 建议使用 UTF-8 编码的 DXF 文件 |
| **文件大小** | 建议单文件 < 20MB，过大文件解析和建模耗时较长 |

### 9.2 FreeCAD 依赖

- **必须安装 FreeCAD 1.0+**：系统通过子进程调用 FreeCAD 的 Python 解释器完成建模
- **路径配置**：`config.yaml` 中 `freecad.bin_path` 必须指向 FreeCAD 的 `bin` 目录
- **首次启动**：FreeCAD 子进程冷启动首次耗时约 **5-8 秒**，后续文件处理热启动约 **1-3 秒/个**
- **Headless 模式**：子进程模式下 FreeCAD 运行在后台，不弹出 GUI 窗口

### 9.3 AI 分析使用建议

- AI 分析会调用 DeepSeek API，每次约消耗 **2-8K tokens**（取决于图纸复杂度）
- 大型图纸（>100 实体）建议先关闭 AI 分析，使用基础模式快速验证
- 分析结果会缓存在 `.cache/analysis/` 目录，有效期 7 天，相同图纸不会重复调用 API

### 9.4 处理性能

| 图纸规模 | 基础模式耗时 | AI 模式耗时 |
|---------|------------|------------|
| 小型 (<20 实体) | ~2 秒 | ~10-30 秒 |
| 中型 (20-80 实体) | ~3-5 秒 | ~30-90 秒 |
| 大型 (80+ 实体) | ~5-10 秒 | ~60-180 秒 |

> 耗时受 FreeCAD 子进程冷/热启动状态影响。连续处理多张图纸时，后续图纸速度会明显快于第一张。

### 9.5 最佳实践

1. **先预览后处理**：双击文件名查看预览，确认图纸内容符合预期再处理
2. **单文件先验证**：拿到新一批图纸时，先用"仅处理选中"模式验证一张，确认参数合适后再批量处理
3. **合理设置拉伸高度**：参考图纸标注或图层信息，过大的拉伸高度会导致 3D 模型比例失调
4. **保留输出目录**：`examples/output/<文件名>/` 中包含所有中间产物（JSON 几何数据、FreeCAD 脚本、分析报告），便于调试和验证
5. **定期清理缓存**：如果修改了 AI 分析参数或图纸内容有更新，运行 `python cache_tool.py clear` 清除旧缓存

## 10. 常见问题排查

### Q: 启动后文件列表为空？

- 确认 `examples/cad_files/` 目录中有 `.dxf` 或 `.dwg` 文件
- 点击「选择文件夹」切换到正确的目录
- 点击「刷新列表」重新扫描

### Q: 预览失败？

- 确认 matplotlib 已安装：`pip install matplotlib`
- 确认 ezdxf 版本 ≥ 1.4.3：`pip show ezdxf`
- 若为 DWG 文件，确认 LibreDWG 已正确配置

### Q: 处理失败，日志显示"FreeCAD not available"？

- 确认 FreeCAD 1.0+ 已安装
- 检查 `config.yaml` 中 `freecad.bin_path` 是否正确
- 运行 `python cad_cli.py --list` 单独测试 FreeCAD 是否可用
- 如果实在无法配置子进程模式，可尝试在 FreeCAD 内置 Python 中启动：`run_with_freecad.bat gui_example.py`

### Q: 处理失败，状态显示 ✗？

- 在底部日志中查看具体错误信息
- 常见原因：
  - 图纸图层不符合规范（无用 OUTLINE/HOLES/SLOTS 命名）
  - 图纸中有无法解析的实体类型
  - FreeCAD 子进程执行脚本出错
- 可以打开命令行运行 `python cad_cli.py -f <问题文件名>` 查看完整错误输出

### Q: 点击"打开 STEP 模型"没有反应？

- 确认处理成功且底部「打开 STEP 模型」按钮为可用状态（非灰色）
- 确认系统中有打开 `.step` 文件的默认程序（如 FreeCAD）
- 若没有关联程序，点击「打开输出目录」手动找到 `.step` 文件并拖入 FreeCAD

### Q: AI 分析模式报错？

- 确认 `config.yaml` 中已配置有效的 `api.deepseek.api_key`
- 确认网络可以访问 `api.deepseek.com`
- 运行 `python examples/scripts/test_api.py` 单独测试 API 连通性
